# CardCargo OLAEET Extractor

Lokale Chrome-/Edge-Erweiterung. Sie liest keine Cookies, Passwörter oder Login-Tokens.
Sie kopiert nur die aktuelle Textauswahl oder `document.body.innerText`.

## Installation

Chrome: `chrome://extensions` -> Entwicklermodus -> Entpackte Erweiterung laden.
Edge: `edge://extensions` -> Entwicklermodus -> Entpackt laden.

Danach OLAEET öffnen, Erweiterung anklicken und den kopierten Text in CardCargo unter
`OLAEET-Pakete -> OLAEET importieren` einlesen.
