# CardCargo – Bunjang Immediate Partial Export v69

Beim Klick auf **Pausieren** oder **Beenden** wird sofort aus allen bereits
vollständig gelesenen Bestellungen ein Teil-Batch erzeugt und in die
Zwischenablage kopiert.

Zusätzlich steht **Bisherige Daten erneut kopieren** zur Verfügung.

## Anwenden

```bash
cd "$HOME/CardCargo/poketracker-pwa"

bash \
  "$HOME/CardCargo/patches/cardcargo-bunjang-immediate-partial-export-v69/apply.sh" \
  "$HOME/CardCargo/poketracker-pwa"
```

Danach die Extension neu laden.

Keine Datenbankmigration erforderlich.
